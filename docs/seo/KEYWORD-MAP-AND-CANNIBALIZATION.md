# Карта запросов и проверка каннибализации (DE, затем 4 языка)

Дата проверки: 17.10.2026. Проверено 112 страниц по sitemap (28 × 4 языка):
title, description, H1–H2, canonical, robots, внутренние ссылки.

> Важно различать два понятия.
>
> 1. **Технические дубли**: одинаковые title, description, H1, дубли URL. Это
>    проверяется кодом и однозначно.
> 2. **Потенциальная конкуренция по поисковому намерению**: две страницы могут
>    претендовать на один запрос. Без данных Google Search Console нельзя
>    утверждать, что они _действительно_ конкурируют в выдаче. Ниже это
>    гипотезы, их нужно проверить по отчёту «Эффективность» (запрос → какие
>    страницы показываются).

## 1. Технические дубли: не найдено

- Одинаковых title, description и H1 внутри языка: **0**.
- Canonical у всех страниц указывает на саму страницу, hreflang полный (de, en,
  ru, uk, x-default), в sitemap нет дублей и адресов с `noindex`.
- Старый адрес `/web-apps` отдаёт 308 на `/web-app-entwickeln-lassen` (не
  дубль).
- Заметка: один немецкий title был 66 символов; сокращён до 63.

## 5. Что проверить после публикации

1. Search Console → «Эффективность» → запрос «web app entwickeln lassen» и
   «individuelle softwareentwicklung»: какая страница показывается (должна быть
   `/web-app-entwickeln-lassen`, не главная и не `/ueber-uns`).
2. То же для «webdesign» и «website erstellen lassen».
3. Если страницы конкурируют, решать по данным: переписать title, перенести
   текст или добавить канонизирующую ссылку.
