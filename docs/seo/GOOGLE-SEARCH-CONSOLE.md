# Google Search Console для Labrity: пошаговая инструкция

Эти шаги выполняются вручную владельцем домена. Код и настройки production мы не меняем.
В репозитории нет следов подтверждения Search Console (нет meta-тега `google-site-verification` и файла `googleXXXX.html`).
Подтверждена ли страница в Google, из кода определить нельзя. Поэтому первый шаг: проверить, есть ли уже такое свойство.

> Важно: ни одна настройка ниже не гарантирует позиций или показов. Search Console показывает реальные данные Google, а не обещает рост.

## 1. Проверить, существует ли свойство

1. Открыть <https://search.google.com/search-console> под аккаунтом владельца сайта.
2. В выпадающем списке свойств посмотреть, есть ли `labrity.com` (свойство «Домен») или `https://www.labrity.com/` (свойство «Префикс URL»).
3. Если есть: перейти к шагу 3. Если нет: шаг 2.

## 2. Добавить и подтвердить свойство «Домен» (рекомендуется)

Свойство «Домен» покрывает `labrity.com`, `www.labrity.com`, все протоколы и поддомены сразу.

1. Search Console → «Добавить ресурс» → тип «Домен» → ввести `labrity.com`.
2. Google покажет TXT-запись вида `google-site-verification=…`.
3. Добавить эту TXT-запись в DNS домена. По данным публичной регистрации (RDAP) DNS-серверы домена: `rzone.de` (Strato), то есть запись добавляется в панели Strato: «Домены → DNS-настройки → TXT-запись для основного домена».
4. Вернуться в Search Console, нажать «Подтвердить». DNS может обновляться от нескольких минут до 24–48 часов.

Альтернатива («Префикс URL» с HTML-файлом или meta-тегом) требует изменения кода и деплоя. Если DNS-способ недоступен, скажите, добавим тег отдельным небольшим PR.

## 3. Отправить sitemap

1. Search Console → «Файлы Sitemap».
2. Ввести `sitemap.xml` (полный адрес: `https://www.labrity.com/sitemap.xml`) → «Отправить».
3. Статус должен стать «Успешно». В sitemap после merge цепочки PR будет около 100 адресов (4 языка).
4. Если Google пишет «Не удалось получить», проверьте в браузере, что `https://www.labrity.com/sitemap.xml` открывается.

## 4. Попросить проиндексировать ключевые страницы

Search Console → «Проверка URL» → вставить адрес → «Запросить индексирование» (лимит небольшой, использовать на самых важных страницах):

- `https://www.labrity.com/`
- `https://www.labrity.com/services`
- `https://www.labrity.com/website-erstellen-lassen`
- `https://www.labrity.com/webdesign`
- `https://www.labrity.com/prices`
- `https://www.labrity.com/blog`

Запрашивать индексацию стоит после merge, иначе Google увидит старые версии.

## 5. Что смотреть в отчётах

| Отчёт | Что проверять |
|---|---|
| «Индексирование страниц» | Сколько страниц «Проиндексировано», причины «Обнаружена, не проиндексирована» и «Просканирована, не проиндексирована» |
| «Эффективность» | Показы, клики, CTR, позиции по запросам и страницам; смотреть за 3 месяца, сравнивать периоды |
| «Основные интернет-показатели» | Реальные данные пользователей (CrUX) по LCP, INP, CLS; данные появляются только при достаточном трафике |
| «Удобство для мобильных» / «HTTPS» | Любые предупреждения |
| «Структурированные данные» / «Хлебные крошки» | Ошибки в Organization, BreadcrumbList, BlogPosting, FAQPage |

## 6. Расписание

- Через 3–7 дней после merge и отправки sitemap: проверить отчёт индексирования.
- Раз в неделю первые 2 месяца: показы, клики, запросы.
- Раз в месяц: основные интернет-показатели и ошибки структурированных данных.
- Сохранять скриншоты «до/после» merge, чтобы честно оценить эффект.

## 7. Ручные настройки вне кода (только владелец)

- **Vercel → Settings → Domains:** редирект `labrity.com → www.labrity.com` сейчас временный (307). Для SEO лучше постоянный (308). Это настройка домена, мы её не меняем.
- **mylabrity.vercel.app:** после merge отдаёт заголовок `X-Robots-Tag: noindex` (см. PR «Производительность и ресурсы»), на основной домен это не влияет.
- **Usercentrics:** в консоли разработчика были ошибки «No ruleset data» (403). Проверить в панели Usercentrics, что домены `labrity.com` и `www.labrity.com` добавлены в разрешённые для ваших настроек; иначе баннер согласия на проде может не работать. Мы это не меняем.
- **Bing Webmaster Tools** (необязательно): <https://www.bing.com/webmasters> → импорт сайта из Google Search Console. Часть AI-поиска опирается на индекс Bing.

## 8. Чего не обещаем

- Сроков попадания в выдачу, позиций и трафика. Домену около 8 месяцев (регистрация 2026-02-05), внешних ссылок по публичным данным нет, поэтому видимость будет расти постепенно и зависит от репутации сайта, а не только от кода.
- Данные Search Console (показы, запросы) нам пока недоступны; все выводы аудита о причинах низких показов остаются гипотезами, пока вы не посмотрите реальные отчёты.
