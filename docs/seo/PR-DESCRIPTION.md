# PR: 5 концепт-проектов, 5 отраслевых страниц под Münster и SEO-правки по сайту

Ветка: `feat/portfolio-concepts-and-industry-pages` → `main`.

## Коротко: ничего не сломано

Этот PR только добавляет контент и улучшает SEO. Сайт после PR #25 работает как
раньше, и проверки это подтверждают (раздел «Проверки» ниже).

**Что мы НЕ трогали:**

- дизайн первого экрана главной, шапку, подвал, фоновое видео;
- калькулятор стоимости и квиз (логика расчёта без изменений);
- контактную форму, `/api/consent`, `/api/telegram`, cookie-баннер;
- middleware, `robots.txt`, настройки безопасности и заголовки;
- SEO-работу из предыдущих PR: canonical, hreflang, Organization-схема с адресом
  и соцсетями, блог и его разметка остались как были;
- страницы портфолио/процесс/контакт/блог/юридические (кроме добавленных
  проектов в портфолио).

**Что изменено:** только то, что описано ниже. Каждое изменение можно откатить
через `git revert` этого PR.

## Что мы сделали

### 1. Портфолио и главная

- Добавлены 5 концепт-проектов из Volodina Web Studio: **Lash Studio Demo,
  Apartament Demo, Billyard, Pizza & Döner, Hausarztpraxis Weber** (номера
  17–21).
- У каждого пометка «Konzept» (как у NØFORM и Premium Consulting), категория,
  описание и ссылка на отраслевую страницу.
- Тексты на de/en/ru/ua взяты из данных Volodina, ничего не выдумано. Ссылки на
  демо ведут на те языковые версии, которые у демо реально есть.
- Данные лежат в `home.json` (`portfolio.items`), поэтому проекты видны и на
  главной, и на `/portfolio`.
- Не добавлены по решению владелицы: Sauber Zeit, AS Abbruch, Zauberer.

### 2. Пять отраслевых страниц под Münster (20 новых URL)

`/website-fuer-arztpraxis`, `/website-fuer-beauty-studio`,
`/website-fuer-pizzeria`, `/website-fuer-billardclub`,
`/website-fuer-apartments`.

- Один общий компонент `IndustryPageClient` в стиле Labrity, данные в
  `src/data/<lang>/industry-*.json`, конфиг в `src/data/industries.ts`.
- **H1 = поисковая фраза** («Website für Arztpraxis in Münster»), рекламная
  строка стала подзаголовком.
- `title`, `description`, canonical, hreflang, FAQ- и Service-разметка
  (`areaServed`: Münster, Germany), хлебные крошки.
- Без фраз «мы из Мюнстера», без вымышленных клиентов, отзывов и гарантий
  позиций. Концепты везде подписаны как вымышленные.
- Добавлены в sitemap, меню (подсветка «Leistungen»), блок «Leistungen» и
  `llms.txt`.

### 3. SEO по всему сайту

- **H1 с поисковой фразой и городом** на страницах: Website erstellen lassen,
  Webdesign, Webentwicklung, Web-App, Website Relaunch, Landingpage, Website für
  Modemarken, Leistungen, Preise (4 языка). Прежний заголовок остался
  подзаголовком (`hero.h1` в данных).
- **`title` и `description` с «Münster»**, все описания не длиннее 160 знаков (у
  отраслевых страниц было до 195).
- Главная, портфолио, процесс, контакт, блог и юридические страницы не менялись.

### 4. Главная страница

- Карусель проектов подгружает все картинки заранее, когда приближается к экрану
  (раньше карточки справа появлялись с задержкой).
- Скриншоты в карточках показываются целиком (`object-contain`), раньше широкие
  скриншоты обрезались по бокам.

## Что мы улучшили

- Поисковая релевантность под Münster: город в H1, `title`, `description` и
  разметке на всех основных страницах услуг.
- Структура для поиска услуги по отрасли: 5 новых посадочных страниц вместо
  одной общей.
- Скорость ощущения главной: картинки не «выскакивают» при прокрутке.
- Единообразие метаданных: длина описаний, один H1 на каждой странице.
